# Troopers

A modern, mobile-first management app for our Scouts BSA troop and Cub Scout pack —
built to replace TroopTrack with a reliable phone experience, role-based
administration, and a frictionless, validated path to sync advancement into
Scouting America's official systems.

See **[PRD.md](./PRD.md)** for the full product requirements document, and
**[HOSTING.md](./HOSTING.md)** for the hosting & infrastructure plan (cost-optimized).

## At a glance
- **Programs:** Scouts BSA (Troop) + Cub Scouts (Pack)
- **Platforms:** Responsive web + iOS + Android
- **Deployment:** Single-unit (self-hosted / private to our troop)
- **Differentiators:** reliable web/mobile parity, position-based permissions,
  one-click validated Scoutbook Plus advancement export, youth-protection &
  COPPA-safe by design.
